# CleanDrive Bot (multi-user, v3.1)

Чистит метаданные (EXIF/GPS/IPTC/XMP) из фото и файлов без потери качества и
складывает результат на **Яндекс.Диск** пользователя. Каждый подключает свой
Диск через OAuth. По итогу — публичная ссылка на папку (доступ по ссылке) и
честный отчёт: что загрузилось, что нет.

## Как это работает
1. `/start` → кнопка «Подключить Яндекс.Диск» → пользователь логинится **на
   странице Яндекса** и разрешает доступ. Пароль бот не видит никогда.
2. Пользователь шлёт фото/файлы (можно альбомом).
3. Бот показывает, что нашёл (в т.ч. ⚠️ GPS), и спрашивает:
   «Очистить метаданные» / «Загрузить как есть».
4. «Обезличить имена?» → при «Да» файлы станут 001, 002, 003…
5. Бот спрашивает имя папки, грузит файлы по одному (если один не
   загрузился — остальные всё равно продолжают грузиться), присылает точный
   отчёт по именам и ссылку на папку.
6. Успешно загруженные исходные сообщения удаляются из чата, чтобы не
   занимать место в переписке.

### О памяти телефона
Бот может удалить **сообщения из чата** после успешной загрузки (Telegram
разрешает ботам удалять входящие сообщения в приватных чатах). Это уберёт
файлы из истории переписки. Но реальную локальную память/кэш телефона
контролирует само приложение Telegram (Настройки → Данные и память) — бот
не имеет доступа к файловой системе устройства и не может мгновенно
гарантировать освобождение места. Если сообщение не удалось удалить
(например, прошло слишком много времени), бот честно сообщит об этом.

## Почему Яндекс, а не Google
Google Cloud недоступен/рискован из Беларуси. Яндекс.Диск свободно доступен в
BY/СНГ, есть полноценный REST API и OAuth.

## Настройка

### 1. Yandex OAuth-приложение
- Зайди на **https://oauth.yandex.ru/** → «Мои приложения» → создать приложение.
- Платформа: **Веб-сервисы**.
- Callback URI (Redirect URI): `https://<твой-render-домен>.onrender.com/oauth/callback`
- Права (scope): **Яндекс.Диск REST API → доступ к папке приложения**
  (`cloud_api:disk.app_folder`).
- Сохрани **ClientID** и **Client secret**.

> Файлы будут лежать в «Приложения/<ИмяПриложения>» на Диске пользователя.
> Если понадобится складывать в произвольную папку на всём Диске — поменяй в
> `config.py` `YANDEX_SCOPE` на `cloud_api:disk.read cloud_api:disk.write` и
> `APP_ROOT` на `disk:/CleanDrive/` (тогда бот создаёт папку в корне Диска).

### 2. Supabase
Зайди на **https://supabase.com/** → новый проект → SQL Editor → выполни:
```sql
create table if not exists disk_users (
  telegram_id bigint primary key,
  access_token text,
  refresh_token text,
  created_at timestamptz default now()
);
```
Возьми `SUPABASE_URL` и service-role `SUPABASE_KEY` из настроек проекта.

### 3. Telegram
Найди **@BotFather** в Telegram → `/newbot` → введи имя → получишь `BOT_TOKEN`.

### 4. Render (Web Service, Docker)
Зайди на **https://render.com/** → New Web Service → подключи репозиторий
(Dockerfile уже есть — нужен ради `exiftool`).
Environment variables:
- `BOT_TOKEN`
- `YANDEX_CLIENT_ID`
- `YANDEX_CLIENT_SECRET`
- `OAUTH_REDIRECT_URI` = `https://<твой-домен>.onrender.com/oauth/callback`
  (ровно как в Yandex-приложении)
- `SUPABASE_URL`
- `SUPABASE_KEY`

`PORT` Render прокидывает сам; на нём поднимается OAuth-callback и `/health`.

## Команды
- `/start` — подключить Диск / инструкция
- `/logout` — удалить токены из базы

## Нюансы
- Присылай как **Файл/Document**, иначе Telegram сам пережмёт «Фото».
- Загрузка идёт по одному файлу; если конкретный файл не загрузился —
  остальные всё равно продолжают, в конце — точный список удачных/неудачных.
- Удаление исходных сообщений из чата — best effort: если Telegram не даст
  удалить (например, сообщение слишком старое), бот сообщит об этом отдельно
  и не будет притворяться, что удаление прошло успешно.
- `pending_states` (OAuth) в памяти — если процесс перезапустится ровно между
  кликом и возвратом с Яндекса, авторизацию нужно повторить.
- Access-токен Яндекса живёт ~1 год; при 401 бот сам обновит его по refresh.
- Имя папки: `/` и `\` заменяются на `-` (вложенность не поддерживается).
- Бесплатный объём Диска: ~10 ГБ (5 базовых + бонусы), либо до 30 ГБ с
  привязкой Яндекс.Почты 360.
